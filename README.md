# BezelPop 3

iPhone-style bezel bulge on Android while a hardware button is held.
Accessibility service + non-touchable overlay; settings in Jetpack Compose (Material 3, Archivo variable font).

Build: push to `main` (or run "Build APK"), download the `BezelPop-apks` artifact, install `app-release.apk`.

Archivo font: SIL Open Font License (see OFL-Archivo.txt).
